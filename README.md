# AI 工作提示詞生成器

給企業業務、行銷、訓練部門使用的 AI 提示詞生成器。選一個工作場景，寫下想要的結果，就會即時組出結構完整的提示詞，複製後貼到 ChatGPT、Claude、Gemini、Copilot 或生圖工具即可使用。

**線上使用：** https://elliehuang37-jpg.github.io/ai-prompt-generator/

## 功能

- **3 個部門 × 20 個場景，共 60 個**
  - 業務：策略簡報、客戶提案、業績檢討、銷售話術、異議處理、開發信、議價策略、群組激勵訊息、業績表揚圖卡等
  - 行銷：活動企劃、品牌主視覺、社群文案、IG 輪播、短影音腳本、SEO 文章、廣告 A/B 測試、活動海報、直播腳本等
  - 訓練：課程大綱、教材簡報、講師逐字稿、測驗題庫、角色扮演、新人 90 天計畫、教練式回饋、知識圖卡等
- **依任務類型提供專屬設定**：簡報可選頁數、敘事框架、視覺風格；圖片可選風格、色調、光線、構圖、比例；影音可選長度與平台
- **圖片提示詞提供兩個版本**：中文通用版（ChatGPT、Gemini、Copilot Designer、Canva AI）與 Midjourney 英文版
- **提示詞完整度提示**：提醒還缺哪些資訊，讓 AI 產出更精準

## 提示詞結構

每份提示詞依以下結構組成：

我真正要的結果 → 做法 → 背景資訊 → 具體要求 → 輸出格式 → 請避免 → 品質標準 → 審稿 → 驗收方式 → 進行方式

提示詞的設計參考 Anthropic 工程主管 Felix Rieseberg 的〈How to be more ambitious: A tutorial for humans with models〉：

- **高度**：先講「完成後希望發生什麼事」，再講要交付的東西；允許 AI 提出比指定形式更好的做法
- **深度**：不叫 AI 扮演專家，而是要它用專家實際的方法、原始資料與工具；先想清楚頂尖專業者會多做什麼；可選擇讓 AI 挑戰你的假設
- **廣度**：借用其他領域的做法（例如簡報借用說故事與決策分析）；由虛擬審稿者真的找出最可能出錯的 3 個地方並修正
- **外部驗收**：不讓 AI 自己打分數，而是列出能在真實情境中驗證成效的指標

其他設計：

- 使用者貼上的背景資料會以 `<背景資料>` 標籤包起來，讓 AI 清楚分辨資料與指令
- 每種任務都有明確的輸出範本（例如簡報逐頁以 `---` 分隔，可直接貼到 Gamma 自動分頁）
- 內建「請避免」清單，減少空泛內容與捏造數據

## 使用方式

1. 選擇部門與工作場景（也可以搜尋關鍵字）
2. 填寫「完成後，你希望發生什麼事」與「要交付的東西」，其他細節可視需要補充
3. 按「複製提示詞」，貼到你使用的 AI 工具

## 技術說明

單一 HTML 檔案，不需要安裝或伺服器，所有內容都在瀏覽器中產生，不會把輸入內容傳送到任何地方。「公司／品牌與產業」欄位會存在使用者自己瀏覽器的 localStorage。

## 提醒

請勿在提示詞中貼入客戶個資、未公開財報等公司機密資訊。
